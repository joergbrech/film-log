How to use Film Log

Film Log is a small logbook for film photography. You note each frame as you shoot it: aperture, shutter, how you metered, where you were, what you wanted. When the scans come back you attach them and write down what you learned. It runs in your browser, works offline, and keeps your data on your device.

Set it up on your phone

1. Put it on the home screen

  1. Open this site in Chrome on Android.
  2. Tap the ⋮ menu in the top right corner.
  3. Tap Add to Home screen, then Install.

Film Log now has its own icon and opens full screen like any other app. After the first visit it also opens without a connection. On an iPhone, use Safari: Share › Add to Home Screen.

2. Allow location, if you want it

When you log a frame, switch on Tag where I am (phone GPS). Chrome asks once whether the site may use your location. After that every new frame picks up your position by itself, until you switch it off again in the same place.

Said no by accident? Tap the icon left of the address bar, or open Android Settings › Apps › Film Log (or Chrome) › Permissions › Location.

3. Set up a backup

Your log is stored inside the browser. That is fast and private, but it is lost if the browser's site data is cleared, the browser is uninstalled or the phone is gone. Set up at least one of the backups below. Until you do, the app shows a reminder.

Logging a roll

  1. + Roll when you load a film. The ISO is read from the film name; set it yourself under Edit roll if you push or pull.
  2. Log frame after each shot. Tap an aperture and a shutter speed, say how you metered, and add a few words. Everything except the frame number is optional.
  3. Sequence shot copies the previous frame with the exposure set to “Kept settings”, for several frames of the same scene. Change what differs and save.
  4. Archive roll when it is finished, and fill in the lab details under Edit roll.
  5. When the scans are back, open a frame, add its scan and write the lesson learned.

Light and EV

If you enter what the meter said (lux or EV), the log shows the EV of your settings and how many stops they are over or under the reading. If you guess the light before you meter, enter the guess too and the log tells you how close you were. All EV values are at ISO 100, the scale light meter apps use.

Location

Switch on Tag where I am and the frame gets your current position. The switch keeps its setting for the following frames, on or off. Frames with a location get a map link. Coordinates are stored as latitude, longitude.

Backup to a folder on the phone

The log can copy itself into a normal folder as plain files. If the browser data is ever lost, the files are still there.

  1. In Film Log, tap Settings.
  2. Under Folder on this device, tap Choose folder.
  3. Create or pick a folder, for example Documents/FilmLog, tap Use this folder and then Allow. Chrome does not accept the Downloads folder itself or the top level of the storage, so use a subfolder.

From then on every save is copied there within a couple of seconds.

  • Chrome asks for access again. After a restart Chrome may want you to confirm the folder. The app shows a Reconnect button, which is one tap. Installing the app to the home screen makes this rarer.
  • Getting the log back. On a fresh browser or a new phone, choose the same folder. If the log is empty it is restored straight away, otherwise tap Restore from folder. Restoring only adds and updates, it never deletes.
  • Protect the folder too. A folder on the phone does not survive a lost phone. Pick one that a sync app (Syncthing, Nextcloud, a cloud drive) already copies elsewhere, or add GitHub sync.
  • No Choose folder button? Folder access needs a recent Chrome on Android (or Chrome or Edge on a computer). Firefox and Safari do not have it. Use Save backup file instead: one file in your downloads, restored with Restore backup file.

Sync to a private GitHub repository

Optional. The log is pushed to a repository that belongs to you, as the same plain files. Useful as an off-phone backup, to read your notes on a computer, or to keep a history of changes.

Once, on github.com

  1. Create a new repository, for example film-log-data. Set it to Private. It may be completely empty.
  2. Open your profile picture › Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token.
  3. Under Repository access choose Only select repositories and pick the new repository.
  4. Under Permissions › Repository permissions set Contents to Read and write. Nothing else is needed.
  5. Choose an expiry date, generate the token and copy it. It starts with github_pat_.

Then, in Film Log

  1. Tap Settings and open GitHub sync.
  2. Enter the owner (your user name), the repository name and the token.
  3. Decide whether scans should be synced too, and whether the app should sync by itself after changes.
  4. Tap Save and test. The app checks the token, warns you if the repository is public, and pushes the log.
  • Sync now pushes the current state. Only files that changed are uploaded.
  • Restore from GitHub merges the repository into the log on this device. It only adds and updates.
  • Sync is one-way: phone to repository. It is a backup, not a way to edit on two devices at once. If you do change a roll's .json file elsewhere, set its updatedAt to the current time and use Restore.
  • The token is stored in this browser only and is sent only to api.github.com. A fine-grained token limited to one repository cannot touch anything else in your account. Turn off removes it from the device; you can also revoke it on GitHub at any time.
  • When the token expires, sync reports that the token was rejected. Generate a new one and paste it in.

The files

Folder backup, GitHub sync and the backup file all use the same layout.

FileWhat it is
rolls/<id>.jsonThe roll and all its frames. This is what restore reads.
rolls/<id>.mdThe same roll as a Markdown table, for reading or for Obsidian. Written fresh on every backup.
scans/<id>/<frame>-….jpgScans you attached to frames.
settings.jsonYour lens and camera lists.

Markdown export and import

Export on a roll gives you the Markdown table to copy or save. Import reads such a table back: frames are matched by number, new ones are added, changed ones updated, nothing deleted. This is also how to bring in a log you kept somewhere else.

Writing the log into your scans

The repository contains tools/tag_scans.py. Give it an exported roll (.md or .json) and the folder of lab scans, and it writes camera, lens, aperture, shutter, ISO, date, location and your notes into the image files, so photo software shows the real shooting data. It needs Python and ExifTool.

python tag_scans.py kodak-gold-200.md scans/ --dry-run

Privacy

  • There is no account, no server and no tracking. The site only delivers the app's files.
  • Your rolls, frames, locations and scans stay in your browser on your device.
  • Data leaves the device only when you set it up: into the folder you chose, into the GitHub repository you named, or into a file you saved.
  • Anyone can use this site for their own log. Everyone gets their own empty log on their own device and nobody sees anyone else's.
